# 계속 새로 쓰는 장치 (권빈 · ALEPH 마지막 A)

새 기록을 넣고 한 번 돌리면 자기소개 사이트의 **숫자 칸**과 **능력별 문단 후보**를 다시 만듭니다.
AI를 부르지 않는 파이썬 스크립트라서, 같은 입력이면 언제 돌려도 같은 결과가 나옵니다. API 키나 비밀값도 필요 없습니다.

## 돌리는 방법 (3단계)

1. **입력 파일을 `input/` 폴더에 넣습니다.**
   - `ritual.txt` : ALEPH 「내 리추얼 기록」에서 「텍스트 파일로 담기」로 받은 파일 (「JSON으로 담기」 파일이면 `ritual.json`으로 넣어도 됩니다)
   - `attendance.json` : 「내 출석 기록」 화면의 숫자 (훈련일·재적일·출석·결석·출석률·기준일)
   - `tasks.csv` : 「내 제출 현황」 과제 목록 (번호, 제목, 주차, 상태)
   - `approved.txt` : 사이트에 넣기로 승인한 후보 id (처음에는 비워 둬도 됩니다)
   - `approved-text.json` : (선택) 승인한 문장의 맞춤법·띄어쓰기를 다듬어 사이트에 실을 때 `{"후보 id": "다듬은 문장"}`
   - `redact.txt` : (선택) 결과에서 가릴 다른 사람 이름
2. **장치를 돌립니다.** 이 README가 있는 폴더에서
   ```
   python renew.py
   ```
   (Python 3.8 이상, 따로 설치할 것 없음. macOS·Linux는 `python3 renew.py`)
3. **결과를 확인하고 승인합니다.** `output/candidates.md`에서 마음에 드는 문장의 id를 `input/approved.txt`에 적고 2단계를 한 번 더 돌립니다. 그러면 `output/site-data.js`가 갱신됩니다. 이 파일을 사이트 폴더의 `data.js`로 덮어쓰고 올리면 사이트가 새로워집니다. (`site/` 폴더가 이 폴더 옆에 있으면 자동으로 갱신됩니다.)

## 같은 결과인지 확인하는 법

실행할 때마다 마지막 줄에 `결과 지문`이 찍힙니다. 두 번 돌려 이 값이 같으면 결과 파일 다섯 개가 한 글자도 다르지 않다는 뜻입니다. 파일별 지문은 `output/SHA256SUMS.txt`에 있습니다.

같은 결과가 나오도록 한 방법은 다음과 같습니다.
- AI 호출, 현재 시각, 난수를 쓰지 않습니다.
- 기준일은 실행한 날이 아니라 기록의 마지막 날짜입니다.
- 후보는 정해진 키워드 표로 고르고, 점수 → 날짜 → id 순으로 정렬합니다.
- 후보 id는 날짜·칸·문장으로 만든 해시라서, 기록이 늘어나도 기존 후보의 id는 바뀌지 않습니다.

## 결과 파일 (`output/`)

| 파일 | 내용 |
|---|---|
| `numbers.json` | 숫자 칸 9개, 각 숫자의 출처(리추얼 기록 / 내 출석 기록 / 내 제출 현황) |
| `candidates.md` | 능력별 문단 후보 8개씩. 날짜, 근거(어느 날 어느 칸), 걸린 키워드 |
| `candidates.json` | 위와 같은 내용(기계용) |
| `peer-feedback.json` | 동료가 말해 준 내 장점 모음(날짜·근거) |
| `site-data.js` | 사이트가 읽는 파일: 숫자 칸과 **승인된** 문장만 들어 있음 |
| `SHA256SUMS.txt` | 결과 파일 지문 |

## 규칙

- 후보는 내가 직접 쓴 칸(강점이 드러난 일화, 강점을 위해 노력하고 생각한 것, 내가 나눈 감사, 나에게 남기는 말, 오늘의 첫 행동)에서만 뽑습니다.
- 한 문장은 키워드가 가장 많이 걸린 능력 하나에만 들어갑니다. 능력마다 같은 날짜에서는 한 문장만 고릅니다.
- 승인하지 않은 후보는 사이트에 들어가지 않습니다.
- 「(이름 가림)」 처리는 ALEPH에서 받을 때 이미 되어 있습니다. 그래도 남은 이름이 있으면 `redact.txt`에 적어 가립니다.
